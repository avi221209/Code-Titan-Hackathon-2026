# Known Limitations

BrandGuardian is an MVP compliance workspace built for Round 2 judging with synthetic workspace data. The constraints below reflect observed behavior and design trade-offs in the codebase today:

1. **English-Only Analysis:** Both deterministic pattern checkers (`\b` word boundaries, English phrasing) and the LLM prompt (`ai-service/main.py`, `language: "en"` default) assume English-language copy. Non-English text is unsupported.
2. **Scoped Regex Fact Matching:** [`check_facts()`](../ai-service/main.py#L158-L177) uses regex patterns configured per row in `approved_facts.match_pattern` (with one capture group) compared against canonical `value`. It only catches facts phrased in structures the configured pattern expects—it does **not** perform open-ended general world fact checking.
3. **Best-Effort Small-LLM Tone & Claim Analysis:** Hosted inference uses Groq `openai/gpt-oss-20b` (`reasoning_effort="low"`, `LLM_TIMEOUT=30`; optional local mode `qwen2.5:3b` via Ollama). Nuanced `tone`, `messaging`, and unpatterned claims are best-effort, labeled **`Unverified`** when no workspace `rule_id` applies, tagged **`AI-generated`**, and accompanied by an **`(estimate)`** confidence percentage.
4. **False-Positive Risk on Broad Promotional Rules (`"best"`, `"guarantee"`):** Seeded regex rules in `supabase/seed.sql` flag patterns containing `\b(?:cheapest|best|number one)...\b` and `\bguarantee[sd]?\b...`. Benign uses (such as `"best practices"`) can trigger false positives and require human `Reject` / `Dismiss` review.
5. **Legacy Client `audit_insert` Policy Remains Active Until `0003` Is Applied:** Although zero browser or user-client code in `web/` inserts into `audit_events`, `0001_schema.sql:235` defines an authenticated `audit_insert` policy. Direct client `audit_events` inserts remain technically permitted via PostgREST until the Project Owner applies [`supabase/migrations/0003_audit_server_only.sql`](../supabase/migrations/0003_audit_server_only.sql) after live M3 decision verification (`USER-RUN`).
6. **Free-Tier Hosting Cold Starts:** Deploying `ai-service` on Render or Railway free tiers causes container sleep after idle periods; the first request can stall unless `/health` is warmed beforehand ([`docs/deployment.md`](deployment.md)). `POST /api/review` sets `maxDuration = 60` (`AbortSignal.timeout(50_000)`) to accommodate upstream latency without hanging indefinitely.
7. **Groq API Rate Limits:** Hosted judging traffic shares project-level Groq token/request rate limits. Burst traffic hitting Groq limits triggers honest `"AI unavailable"` degraded mode (`ai_status = 'unavailable'`) while preserving deterministic findings.
8. **Python Unicode Code-Point vs JavaScript UTF-16 Offsets:** Python `start_offset` / `end_offset` values index Unicode code points, whereas JavaScript strings index UTF-16 code units. [`resolveHighlightSpan`](../web/lib/validators/review.ts) and [`applyAcceptedEditsToDocument`](../web/lib/validators/decision.ts) check exact `slice(start, end) === matched_text` and fall back to `indexOf(matched_text)` when surrogate-pair characters (e.g., emojis) shift offsets, skipping unmatched spans rather than corrupting copy.
9. **Open Tier B Defect `[DEF-09]` — ESLint Script & Transitive `postcss` Advisories:** `web/package.json` does not include an ESLint `"lint"` script, and `pnpm audit --json` reports `4` transitive `next > postcss <= 8.5.22` advisories (`2 high`, `2 moderate`, `0 critical`).
10. **Open Tier B Defect `[DEF-11]` — Cold `/dashboard` SSR Latency (`4.22s` vs `1.56s` Median):** Protected SSR navigation to `/dashboard` runs sequential remote `supabase.auth.getUser()` verification in both `web/middleware.ts` and `web/lib/workspace.ts`, measured on `next start -p 3000` at `[4224.2, 1559.9, 1309.2, 1613.7, 1399.3] ms` (`4.22s` cold first load vs `1.56s` median).
11. **Open Tier B Defect `[DEF-12]` — Streaming `loading.tsx` Soft-404 Status (`HTTP 200`):** Route-segment `loading.tsx` `<Suspense>` boundaries stream `HTTP 200` headers before async `notFound()` renders `<h1>Page not found</h1>` on invalid or missing document UUIDs (`/documents/not-a-uuid`, `/documents/<missing>/history`).
12. **Input Scope, Read-Only Preview & Unbuilt Features:** Submitted content is capped at `6,000` characters (`MAX_DOCUMENT_CONTENT_LENGTH = 6000`). `"Preview final text"` is read-only clipboard copy and does not overwrite the stored draft. PDF/DOCX ingestion, image/logo checks, analytics dashboards, comments UI (`comments` table exists in schema only), reviewer assignment, and knowledge CRUD UI are **not built**.
